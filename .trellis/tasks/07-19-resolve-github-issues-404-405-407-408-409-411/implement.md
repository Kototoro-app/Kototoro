## 风险点

- 动态轮播图片无法提供稳定的“取图片主色”时，不引入昂贵的逐帧分析；优先使用低 alpha、较长过渡和主题中性渐变。
- Backdrop 消费者不得进入自身 source 子树，避免渲染循环和 RenderThread 崩溃。
- projection 修复不得用 UI `take(n)` 或数据库破坏性删除解决显示问题。
- OOM 修复不得以全局 `catch (OutOfMemoryError)` 作为主要方案。
