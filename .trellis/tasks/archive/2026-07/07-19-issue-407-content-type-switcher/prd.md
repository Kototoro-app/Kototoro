# Issue 407：修复内容类型过滤器展开面板

## Goal

在关闭 Space 的前提下，修复主界面顶栏右侧内容类型过滤按钮的长按拖拽面板，使其完整呈现视频、漫画、小说三项，并使用正确的 Backdrop 玻璃效果。

## Requirements

- 原始漫画按钮作为中心，长按原地展开，左右顺序为视频 - 漫画 - 小说。
- 拖拽后松开按位置切换内容类型，保留无障碍和点击语义。
- 小说按钮必须显示，面板使用同窗口 Backdrop/root overlay。
- 原始切换按钮本身不增加额外视觉容器；不影响 Space 开启时的主导航。

## Acceptance Criteria

- [ ] 三项按钮均显示且顺序、中心锚点正确。
- [ ] 长按、拖拽、松开切换及取消手势均稳定。
- [ ] iOS 风格有 Backdrop，Backdrop 不可用时安全静态降级；无自包含采样。
- [ ] 原始按钮无额外容器，Material 3 和 Space 开启路径无回归。
- [ ] 手势/布局纯逻辑测试、编译和 `git diff --check` 通过。

## Notes

已有 `07-17-unify-popup-menu-glass` 任务提供根层玻璃菜单基础设施，本子任务只补内容类型过滤器的专属展开和布局行为。
