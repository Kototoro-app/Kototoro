# 本地文件导入指南

Kototoro 支持直接将本地离线存储的内容导入到应用中。你可以明确指定将文件作为 **漫画**、**小说** 还是 **视频** 导入。

根据文件形式，可选用“导入单文件”或针对结构化目录的“导入文件夹”模式。

---

## 支持的文件格式

在导入时如果强制指定了内容大类，所选文件格式必须严格符合该类别的支持规范，否则应用会拦截导入以防止阅读或解码报错：

- **漫画 / 画集**：`.zip`、`.cbz`，或包含图片文件的普通文件夹（支持 `.jpg`、`.png`、`.webp` 等格式）。
- **小说 / 文本**：`.epub`、`.txt`。
- **视频 / 动画**：`.mp4`、`.mkv`、`.ts`、`.webm`、`.avi`、`.m3u8`。

> [!NOTE]  
> 若未手动指定大类而使用 **自动检测**（Auto-detect），Kototoro 会依据后缀名推断。但在导入 `.txt` 纯文本或混合内容目录时，强烈建议手动明确指定内容类型。

---

## 推荐的目录组织结构

如果你拥有多个章节或剧集文件，可以通过“导入文件夹”将其整合为一部完整的作品：

### 1. 单作品文件夹导入（Single item）
适用于一个文件夹包含**同一部作品的所有章节或剧集**。  
文件夹名将作为作品标题，其中的每个文件会被解析为一话或一集。

**视频系列示例：**
```text
[文件夹] 进击的巨人 第一季/
  ├─ 01.mp4
  ├─ 02.mp4
  └─ 03.mkv
```

**小说章节示例：**
```text
[文件夹] 我的网络小说/
  ├─ 第一章.txt
  ├─ 第二章.txt
  └─ 第三章.txt
```

### 2. 多作品库文件夹导入（Multiple items）
适用于一个总目录内包含了**多部不同作品**的大型本地媒体库。  
其中的每个子文件夹会被分别识别为独立的作品，子文件夹内的内容为该作章节。

**示例：**
```text
[总文件夹] 我的本地动漫库/  （导入时选择此文件夹）
  │
  ├─ [文件夹] 火影忍者/
  │    ├─ 第01集.mp4
  │    └─ 第02集.mp4
  │
  └─ [文件夹] 死神/
       ├─ 第01集.mkv
       └─ 第02集.mkv
```

> [!TIP]
> 在“多作品”模式下，根目录下若存在零散的单文件（如单个 `.mp4` 或 `.epub`），也会被作为独立的单部作品导入，并以文件名作为作品标题。

## 元数据与 `index.json`

Kototoro 支持通过目录根部存放的 `index.json` 文件读取自定义元数据。

### 能否识别现有的 `index.json`？
**可以**。如果文件夹或 `.zip` / `.cbz` 压缩包根部包含格式正确的 `index.json`，本地解析器会在导入时直接读取，将自定义标题、作者、简介、封面图、分类标签以及章节分卷映射到你的书库中。

### 是否会自动生成 `index.json`？
**是的**。Kototoro 在扫描或首次导入未包含该文件的目录时，会自动根据目录名与文件名合成一份基础的 `index.json` 保存在该作品目录下，方便后续元数据持久化。

### 用户能否手动修改信息？
**完全可以**。
1. **直接编辑文件**：使用文件管理器进入作品文件夹，用文本编辑器打开并修改 `index.json`，你可以更正标题、作者名、标签或修改封面路径。Kototoro 在下一次扫描时会严格尊重你的修改。
2. **应用内编辑**：在应用内的作品详情页也可直接编辑标题与元数据，修改会写回本地配置。

---

## 如何操作导入

1. 打开 **设置 → 内容源 → 本地存储**。
2. 点击右下角的 **+**（导入）按钮。
3. 在弹窗顶部明确选择目标 **内容类型**（漫画、小说或视频）。
4. 选择导入模式：单个文件、单个作品文件夹或多作品总目录。
5. 系统将开始扫描与建立追踪索引，收到完成通知后即可在书库或浏览中查阅。
