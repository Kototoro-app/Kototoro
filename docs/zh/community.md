# 社区功能指南

Kototoro 内置了去中心化、无自建服务器的社区系统，支持作品评分、评论讨论、全站排行榜以及本地个性化推荐。

与依赖专有中心化后端的传统软件不同，Kototoro 的社区建立在**公共 Nostr 中继**（负责身份验证与实时事件广播）以及**定时生成的静态快照索引**（托管在 GitHub Pages 上）之上。个性化计算与隐私过滤则 100% 在用户设备本地完成。

---

## 核心设计与架构

- **零自建服务器**：不设立任何中心化服务器，读者身份与互动事件完全运行在开放的 Nostr 协议上。
- **轻量与秒级响应**：后台索引器（`community-indexer`）每 6 小时将各中继数据清洗聚合并生成静态快照（分片 JSON），通过 CDN 分发。客户端秒级载入分片快照，仅在发布事件或浏览最新回复时连接实时中继。
- **本地隐私至上**：你的书库、收藏、阅读历史绝不会上传到任何服务器。个性化“社区推荐”是在本地利用公开的物品相似度矩阵，与你的本地书库偏好进行实时交叉计算。
- **明确授权与透明**：功能默认关闭。用户自主掌控密码学密钥对、评分权限、成人作品边界与来源分享开关。

```
 客户端 ── 签名事件（评分 / 评论） ──▶ 公共 Nostr 中继 ×4–6
    ▲                  ▲                        │
    │                  │                        │ 定时拉取
    │         实时订阅（章节评论 / 回复我）          ▼
    │                                  GitHub Actions（community-indexer）
    │                                           │
    │                                           ▼ 生成静态快照
    └────────────── 下载静态分片快照 ◀──── GitHub Pages（community-index）
```

## 开启与配置

### 1. 开启社区功能
1. 打开 **设置**。
2. 进入 **服务 → 社区**。
3. 勾选 **社区评分**。

首次开启时，向导会自动为你的设备生成本地加密密钥对。

### 2. 身份与恢复密钥（Recovery Key）
社区身份无需邮箱、手机号或任何第三方账号：
- 本地生成标准 **secp256k1 密钥对**。
- 公钥（`npub1...`）作为你在全网中继的公开匿名标识。
- 私钥（`nsec1...`）即为你的**恢复密钥**。

> [!CAUTION]
> **请务必妥善备份恢复密钥！**  
> 若重装应用或切换设备，必须通过 `nsec1...` 密钥导入才能继续管理自己的既有评分与昵称。  
> 出于安全考虑，恢复密钥**不会**被打包进普通的备份 ZIP 文件中。请将其抄写在安全处或存入密码管理器。

### 3. 设置公开昵称
1. 在 `设置 → 服务 → 社区` 中点击 **社区昵称**。
2. 输入你的昵称并点击 **公开保存**。
3. 应用将向中继发布一条 Kind 0 元数据事件。其他读者在浏览你的评论与评分时将显示该昵称。

## 隐私与内容合规保护

由于 Nostr 上的事件具有公开且不可篡改的特性，Kototoro 引入了多项隐私与合规保护机制：

### 公开与不可抹除特性
- 评分与评论经由你的私钥签名并广播至多个公共中继。
- 撤销评分或删除评论会广播一条删除事件（NIP-09），索引器在后续快照中会剔除该记录，但公共中继可能仍留存历史日志。

### 成人（NSFW）内容控制
- **为成人作品评分**（`设置 → 服务 → 社区 → 为成人作品评分`）：**默认关闭**。
- 关闭时，应用自动阻断任何成人/NSFW 标签作品的评分与评论提交。
- 开启后，成人评分会自动附带内容警告标签（`content-warning: nsfw`），并在榜单中与常规作品严格隔离。

### 来源分享策略
- **发布时附带来源**（`设置 → 服务 → 社区 → 发布时附带来源`）：
  - 开启后（默认开启），评分和评论会带上当前阅读来源的提示标签，方便其他读者找到在哪里能阅读该作品。
  - **安全边界**：仅公开通用扩展插件与内置解析器来源；本地导入文件、用户私有配置的 TVBox/Legado/LNReader 等自定义 JSON 来源**绝对不会被公开**。

## 功能详述

### 1. 作品评分与贝叶斯平均
- **评分打分**：在作品详情页点击 **评分**，可进行 1–10 分（对应 1–5 星，支持半星）评价。
- **撤销评分**：可在评分对话框中随时撤销评分。
- **贝叶斯均分算法**：索引器通过贝叶斯平均对各作品评分进行加权平滑：
  $$\text{Score} = \frac{v \cdot R + m \cdot C}{v + m}$$
  有效避免只有一人打 10 分的作品虚高霸榜。
- **跨源作品识别**：利用强标识（AniList、MAL、Bangumi、Kitsu 等外部标准链接）与标准化折叠标题进行跨源聚合，确保不同语言与来源的同一部作品平滑归一。

### 2. 评论与讨论
- **作品级评论**：在作品详情页轻触评论入口展开弹窗，支持顶级评论与楼中楼嵌套回复。
- **章节讨论**：在阅读漫画或小说时，章末会显示 **本章评论** 入口，精准聚焦单话剧情讨论。
- **防剧透机制**：带有剧透标记的评论默认模糊隐藏，点击后方可展开阅读。
- **作者屏蔽与举报**：长按任意评论可进行回复、复制、举报不良内容或直接屏蔽作者。屏蔽后本地将自动隐藏该作者的所有发言与评分。

### 3. 全网社区榜单
在 **探索 / 推荐** 页面中汇聚了全站读者的评分排行：
- **时间跨度**：支持查看 **本周**、**本月** 或 **全时段** 热门与高分榜。
- **媒介分类**：漫画、小说、视频分榜展示。
- **门槛限制**：只有获得足够置信评分人数的作品才会进入排行榜。

### 4. 社区精选（本地协同过滤推荐）
- 基于你在本地打出高分（$\ge 7$ 分）、收藏或完读的作品作为种子。
- 在本地与静态快照中的余弦相似度矩阵计算关联度，推荐“因为你喜欢《…》”。
- 自动检测并优先为你匹配本地已安装的可用来源。

### 5. “在此阅读”来源指引
- 在榜单或详情页中，卡片会标注其他读者的阅读来源（如 *“12 位读者在此阅读”*）。
- 长按卡片或点击“其他来源”可直接查看并调起本地兼容的扩展源进行阅读。

## 中继与网络容灾

- **默认中继池**：内置 `wss://nos.lol`、`wss://relay.primal.net`、`wss://nostr.mom`、`wss://relay.nostr.wirednet.jp` 等可用中继。
- **发件箱离线重试**：网络不通时，签名的事件暂存在本地发件箱，等待网络恢复后由 WorkManager 自动重发。
- **防 DNS 污染与解析优化**：内置 `CommunityRelayDns`，依次通过 Cloudflare、Google 与 DNSPod 的 DoH 进行域名解析，有效抵抗网络阻断。
