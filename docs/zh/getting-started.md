# 快速入门指南

这是新用户最理想的起步指南。目标很简单：安装应用、配置你需要的源，并在真正需要时再开启高级特性。

> [!IMPORTANT]
> **Kototoro 不包含任何内置内容或媒体。** 它仅是一个通用的阅读与播放框架。用户必须自行安装第三方扩展、导入本地文件或配置外部接口。开发者与任何内容提供方无关，亦不对用户获取的内容负责。

本指南以 Android 版本为主。若使用 Windows 或 iOS，请先阅读 [Windows 与 iOS（预览版）](./platforms.md)。

---

## Kototoro 的核心优势

1. **三合一应用**：一个应用统一管理漫画、小说与视频。
2. **内置 OCR 与翻译**：无需切换外部工具，直接在阅读界面内翻译页面或段落。
3. **影音增强体验**：视频超分辨率（Anime4K）、DLNA 局域网投屏、内嵌/外部字幕与音轨切换。
4. **多站进度追踪**：无缝对接 MAL、Kitsu、AniList、Bangumi、Shikimori、MangaUpdates。
5. **去中心化社区**：基于 Nostr 与静态快照的评分、评论讨论与本地隐私推荐。
6. **跨设备同步**：通过标准 WebDAV 稳定合并多端书库与阅读进度。
7. **广阔的源生态**：原生支持内置源插件、Kotatsu-Redo、Mihon、Aniyomi、IReader、Legado 及 TVBox。

---

## 10 分钟快速上手

1. 从 [Releases 页面](https://github.com/Kototoro-app/Kototoro/releases) 下载并安装最新的 APK 安装包。
2. 打开应用，按照首次启动的**设置向导**选择你常用的语言、启用的内容类型并安装内置插件。
3. 根据个人需求添加外部扩展源（如 Mihon 或 Legado）。
4. 若有多设备使用需求，建议在建立大型书库前配置好 WebDAV。
5. 如需翻译生肉漫画，可在设置中配置 OCR 与翻译模型。

## 设置向导

首次启动时，Kototoro 会引导你完成初始化向导。

### 重新打开向导
如果你跳过了向导或想重新运行，可随时进入：
`设置 → 内容源 → 设置向导`

### 1. 语言与内容大类
- 选择感兴趣的源语言（如中文、英文、日文等）。
- 选择在应用中全局启用的媒体类型：
  - **漫画**
  - **小说**
  - **视频**

### 2. 内置源插件初始化
Kototoro 的内置动态解析器（包括核心 Kototoro 解析器与 Kotatsu-Redo 解析库）以动态插件的形式发布：
1. **GitHub 镜像加速**：在网络受限或访问 GitHub 缓慢的地区，可在镜像下拉框中选择 `GHProxy` 等可用节点。
2. **勾选插件仓库**：选择需要启用的插件源。
3. **部署安装**：点击部署按钮，应用将自动下载并装载最新的解析插件。

这是最推荐的开箱即用方式。

## 根据需求选择你的路径

### 漫画用户
1. 先查看内置源与插件源。
2. 若同时使用 Mihon，在系统上安装需要的 Mihon 扩展 APK，Kototoro 会自动识别；或进入 `设置 → 内容源 → 扩展 → 漫画` 添加扩展仓库直接在应用内安装。
3. 详见 [内容源生态集成](./source-integrations.md)。

### 视频用户
1. **Aniyomi 扩展生态**：在 `设置 → 内容源 → 扩展 → 视频` 中安装扩展 APK。
2. **TVBox 订阅**：准备 JSON 链接或本地文件，进入 `设置 → 内容源 → 导入 JSON 源` 导入。
3. 播放时支持手势快进、字幕/音轨选择以及 DLNA 局域网投屏。
4. 详见 [阅读器与播放器特性](./reader-features.md)。

### 小说用户
1. 使用内置小说解析器或 IReader 扩展。
2. 若使用**阅读（Legado）**书源，在 `设置 → 内容源 → 导入 JSON 源` 导入书源规则（支持单源或批量源链接）。
3. 详见 [内容源生态集成](./source-integrations.md)。

## 可选高级功能

### 社区功能（评分与讨论）
1. 打开 `设置 → 服务 → 社区`。
2. 开启 **社区评分**。
3. 本地生成并**妥善抄写保存恢复密钥**（`nsec1...`）。
4. 设置一个向其他读者展示的公开昵称。
5. 详见 [社区功能指南](./community.md)。

### 推荐与探索
1. 打开底栏或侧边栏的 **探索 / 推荐**。
2. 系统会根据本地阅读习惯和社区协同过滤生成多维度推荐（口味、热门、探索、社区精选）。
3. 详见 [推荐与发现指南](./recommendations.md)。

### WebDAV 多端同步
1. 打开 `设置 → 备份与还原`。
2. 填入 WebDAV 服务器地址、用户名与密码。
3. 运行一次手动备份；随后在另一台设备上执行还原。
4. 详见 [WebDAV 同步指南](./webdav-sync.md)。

### 自动翻译与 OCR
1. 打开 `设置 → AI → 翻译`。
2. 选择目标语言与翻译模式（`本地` 或 `仅 API`）。
3. 初次使用推荐选用 `基础` OCR，开箱即用。
4. 详见 [自动翻译指南](./automatic-translation.md)。
