# 问题排查与修复 (Troubleshooting)

本页面汇集了在日常使用、源扩展集成与多端同步中最常出现的异常问题及对应的解决步骤。

---

## 内容源相关问题

### Mihon 或 Aniyomi 扩展未出现
1. 确认扩展 APK 是否确实已经安装在当前设备上。
2. 若使用应用内扩展仓库安装，确认仓库刷新成功且下载安装未被系统权限拦截。
3. 进入 `设置 → 内容源 → 扩展`，下拉刷新列表。
4. 检查 `浏览 → 内容源` 对应的媒体标签（漫画或视频）中是否已有该源。
5. 某些过旧或不兼容的扩展可能无法被反射加载，请尝试更新扩展至最新版。

### IReader 小说源未出现
1. 确认 IReader 扩展 APK 已经安装。
2. 彻底退出并重新打开 Kototoro（应用在启动时会自动扫描已安装的扩展）。
3. 检查 `浏览 → 内容源` 中的小说分类。

### Legado 书源或 TVBox 源无法导入或不显示
1. 确认 JSON 网址链接可正常访问，或本地 JSON 文件未损坏。
2. 重新进入 `设置 → 内容源 → 导入 JSON 源` 尝试再次导入。
3. 进入 `设置 → 内容源 → JSON 源目录`，确认导入的源条目处于**启用（勾选）**状态。
4. 建议初次先导入单个书源测试，再批量导入大合集。

### TVBox 导入成功但无法加载剧集或播放失败
1. 确认该源的具体类别：直连直链媒体、M3U 播放列表、CMS 接口、JavaScript 源、普通 JAR 爬虫或加密 Guard 原生源。
2. 直链媒体与标准 CMS 接口兼容性最高，建议优先验证。
3. 若为 `type = 4` 的 JavaScript 源报错，可能是该源使用了目前尚未兼容的 JS 沙箱特性。
4. 若为普通 `type = 3` / `csp_*` JAR 爬虫失败，请使用抓取日志查看是否缺失类或方法。
5. 加密型 Guard-native JAR 依赖底层的特定 JNI 动态库，本地未必能完整模拟，详见 [TVBox 运行时兼容性](../reference/tvbox-runtime.md)。

### 内置源或 Kotatsu-Redo 源提示加载失败
1. 目标源站可能启用了 Cloudflare 人机验证，注意界面是否弹出了浏览器验证窗口。
2. 按照提示完成 Cloudflare 验证。
3. 若验证窗口未弹出或一直转圈，尝试在右上角菜单中手动刷新或检查系统 WebView 版本。
4. 部分境外网站存在地域访问限制，请配合网络代理环境使用。

## 自动翻译与 OCR 问题

### 开启了翻译但页面完全没有变化
1. 确认作品源语言与目标语言是否设置相同；若两者一致，系统会自动跳过无需翻译的页面。
2. 重新检查源语言，若“自动检测”识别不准，可强制指定源语言（如日语 `Japanese`）。
3. 在 `仅 API` 模式下，务必在“在线翻译服务”中确认 API 地址、Key 和模型名称均已正确填入并通过连接测试。
4. 若选用 `高级` OCR 模式，请确保所有检测与识别模型均已完整下载且校验通过。

### 模型下载失败或中断
1. 检查设备的存储空间是否充足。
2. 检查网络连接（如从 GitHub 下载模型受限，可在设置中切换镜像加速节点）。
3. 重新打开 `本地模型管理` 重新下载。

### 远端 API 翻译报错
1. 核对 API Key 的余额与有效性。
2. 点击 **测试连接并选择模型**；若模型列表拉取失败，请手动输入模型名称（如 `gpt-4o-mini` 或 `deepseek-chat`）。
3. 注意：当前版本不会自动在本地与 API 之间静默回退，请确认当前处于你期望的翻译模式中。

## WebDAV 同步问题

### 两台设备的数据不一致
1. 选择拥有最新正确书库的设备，执行一次手动“立即备份”。
2. 在另一台落后的设备上，点击“从备份还原”。
3. 待两端状态一致后，再继续日常的使用与同步。

### 备份或还原时提示连接错误
1. 仔细检查 WebDAV 地址末尾是否需要补充斜杠 `/`。
2. 校验用户名与密码（如使用坚果云等服务，必须使用在网页端生成的专用应用密码）。
3. 在 WebDAV 网盘根目录下手动新建名为 `kototoro` 的专用文件夹并将其设为端点路径。

## 视频播放器问题

### DLNA 投屏找不到设备
1. 确保手机与电视/盒子处于同一个 Wi-Fi 局域网内。
2. 确认接收端设备的 DLNA/投屏功能已开启。
3. 部分公共 Wi-Fi 或路由器开启了“AP 隔离”（禁止设备互访），需关闭该选项。

### 字幕未显示
1. 确认片源本身是否包含内嵌字幕轨。
2. 点击播放器底部的设置菜单，检查字幕轨道选择。
3. 也可以手动从本地加载外部 `.srt` 或 `.ass` 字幕。

### Anime4K 滤镜看不出明显变化
1. Anime4K 对较低分辨率（如 480p/720p）上采样到 1080p/4K 屏幕时提升最为明显。
2. 若播放源本身已经是 1080p 或 4K 高码率内容，滤镜的边缘锐化差异相对微弱。
