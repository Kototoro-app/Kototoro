# 内容源生态集成

除自身内置解析器外，Kototoro 还支持接入多个外部第三方源生态。本文档将指导你如何在应用中导入、安装与管理这些扩展源。

---

## 概述

Kototoro 支持的内容源生态包括：

- **内置解析源**（原生 Kototoro 解析器 + Kotatsu-Redo 解析库）
- **Mihon 漫画扩展**
- **Aniyomi 视频 / 动漫扩展**
- **IReader 小说扩展**
- **Legado（阅读）JSON 书源**
- **TVBox JSON 视频源与直播配置**

配置完成后，所有外部源均会统一展示在 `浏览 → 内容源` 中，其浏览、搜索、收藏、阅读与播放体验与内置源完全一致。

---

## 界面入口提示

在简体中文界面中，相关的管理页面位于：  
`设置 → 内容源`

在部分旧版本或英文翻译中，该页面可能被标为 `设置 → 漫画源`（Manga sources）。由于该页面目前统一管理漫画、小说、视频以及各类 JSON 订阅源，请认准“内容源”入口。

---

## 内置源与 Kotatsu-Redo 插件

Kototoro 随安装包打包了核心原生解析器，并以动态插件的形式集成了整个 Kotatsu-Redo 解析器生态。

- 在 `浏览 → 内容源` 中直接可用。
- 解析器规则更新随应用版本或动态插件更新下发。
- 内置针对 Cloudflare 防护源的自动解算机制（通过静默 WebView 解算或交互式验证流）。

---

## Mihon 与 Aniyomi 扩展生态

Kototoro 深度兼容 Mihon（漫画）和 Aniyomi（视频）扩展体系：

### 工作原理
- 应用通过检测系统内安装的对应扩展 APK，直接在 Kototoro 中反射调用扩展逻辑。
- 你既可以在外部安装扩展 APK 后让 Kototoro 自动检测；
- 也可以在 Kototoro 内部直接配置兼容的扩展仓库（Extension Repository），直接在应用内完成浏览、安装、更新与卸载。

### 配置步骤
1. 打开 `设置 → 内容源 → 扩展`。
2. 切换至对应的大类标签：
   - 漫画：对应 Mihon 扩展生态。
   - 视频：对应 Aniyomi 扩展生态。
3. 点击添加扩展仓库链接。
4. 在列表中找到需要的扩展直接点击安装。
5. 返回 `浏览 → 内容源` 即可看到新增的来源。

## Legado（阅读 3.0）小说书源

Kototoro 原生支持导入 Legado 的 JSON 格式书源规则：

1. 准备好书源的 JSON 网址链接（URL）或本地 `.json` 文件。
2. 进入 `设置 → 内容源 → 导入 JSON 源`。
3. 粘贴网络链接或选择本地文件完成解析导入。
4. 导入后可在 `设置 → 内容源 → JSON 源目录` 中查看、启用或批量管理书源。

---

## TVBox 视频与直播源

对于影视和流媒体，Kototoro 支持直接导入 TVBox 的配置订阅：

1. 准备 TVBox 配置链接（支持单源、多源集合聚合链接）。
2. 进入 `设置 → 内容源 → 导入 JSON 源`。
3. 输入链接并确认导入。
4. 解析成功后，源站分类、搜索与剧集列表将在 `浏览 → 内容源` 的视频分区中立即可用。
5. 详细支持矩阵请参阅 [TVBox 运行时兼容性](../reference/tvbox-runtime.md)。
