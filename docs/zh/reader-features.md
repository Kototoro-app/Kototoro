# 阅读器与播放器特性

Kototoro 是一款多合一的内容消费应用，而不是单一目的的漫画阅读器。本文档梳理了面向用户的核心阅读与视听特性。

---

## 核心产品领域

### 漫画、小说与视频三合一
Kototoro 将三大媒体类型融为一体：
- **漫画**（在线与本地 CBZ/ZIP/PDF/文件夹）
- **小说**（在线小说源、本地 EPUB、TXT）
- **视频**（在线影视源、本地 MKV、MP4 等）

所有媒体共用统一的收藏夹、历史记录、下载管理器以及 WebDAV 跨设备同步流，免去在多个应用间反复切换的繁琐。

---

## 漫画与图像阅读器

- **多种排版与翻页模式**：
  - 从右向左（日漫习惯）
  - 从左向右（西漫与传统阅读）
  - 垂直无缝滚动（条漫 / Webtoon 模式）
  - 展开双页与智能分页对齐
- **跨章节无缝阅读**：翻至章节末尾自动过渡到下一话，无强制卡顿感。
- **画质超分辨率（Super-Resolution）**：
  - 搭载基于 NCNN 的 **RealCUGAN**、**Real-ESRGAN** 与 **Anime4K** 放大算法。
  - 支持在阅读中实时对低分辨率模糊图源进行 2x 降噪放大，画面平滑锐利。
- **本地书签与截屏提取**：方便长按保存精美插图或记录特定页面。
- **章末互动**：章节末尾提供直达的社区讨论入口，与其他读者交流单话剧情。

---

## 小说阅读器

- **排版引擎**：支持段落自动对齐、行间距微调、字体替换、边距自适应。
- **沉浸式主题**：深色、纯黑、羊皮纸色、水墨屏高对比度模式。
- **目录跳转与智能分章**：本地 TXT/EPUB 智能正则分章，在线源实时加载目录。
- **双语对照与翻译流**：接入本地/在线翻译时，段落支持逐段对照展示。
- **TTS 语音朗读**：调用系统 TTS 引擎完成听书阅读。

---

## 内置视频播放器

基于优化的硬解码播放核心（Android 端基于 Media3/ExoPlayer，桌面端集成 mpv）：

- **流媒体与分段选择**：支持清晰度切换与分段预加载。
- **字幕与多音轨切换**：
  - 完美支持内嵌字幕（ASS/SRT/VTT）与外挂本地字幕文件。
  - 支持多语言音轨无缝切换。
- **Anime4K 视频画质增强**：可在播放菜单中开启实时动漫滤镜，画面边缘锐化、噪点抑制。
- **DLNA 局域网投屏**：利用 SSDP 自动发现局域网内的智能电视或机顶盒，一键投屏大屏播放。
- **手势操作**：屏幕左右侧滑动调节亮度与音量，水平滑动触发比例微调进度条。

| **Kitsu** | ✅ 趋势推荐、分类浏览 | ✅ |
| **AniList** | ✅ 热门、正在播出 | ✅ |
| **Bangumi（番组计划）** | ✅ | ✅ |
| **Shikimori** | ✅ | ✅ |
| **MangaUpdates** | ✅ | ✅ |
