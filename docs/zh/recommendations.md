# 推荐与发现

Kototoro 搭载了注重隐私与个性化的多源推荐引擎，无需上传你的任何书库或阅读数据，即可在各个已安装的内容源中帮助你发现精彩的漫画、小说与视频。

推荐引擎由 **本地内容品味建模**、**内容源目录探索** 以及 **去中心化社区协同过滤** 共同驱动。

---

## 推荐机制全景

推荐内容集中展示在应用主界面的 **探索 / 推荐** 页面中。Kototoro 不采用单一混乱的信息流，而是将候选作品按 5 种不同的**推荐方向**归类并呈现：

```
 ┌─────────────────────────────────────────────────────────────┐
 │                      本地书库与阅读记录                      │
 │              （收藏夹、阅读进度、最近阅读、评分）              │
 └──────────────┬──────────────────────────────┬───────────────┘
                │                              │
          品味画像建模                           种子筛选
        （标签 + TF-IDF）                   （高分与完读作品）
                │                              │
                ▼                              ▼
 ┌─────────────────────────────┐┌──────────────────────────────┐
 │         基于源的推荐         ││          基于社区的推荐       │
 │  • 口味（命中核心偏好标签）   ││  • 社区精选                 │
 │  • 热门（源站热门榜单）       ││    （“因为你喜欢《…》”）     │
 │  • 最新（源站新入库作品）     ││  • 评分质量加权              │
 │  • 探索（未尝试过的题材）     ││    （高分提权 / 低分过滤）   │
 └──────────────┬──────────────┘└──────────────┬───────────────┘
                │                              │
                └──────────────┬───────────────┘
                               ▼
 ┌─────────────────────────────────────────────────────────────┐
 │                本地多样性打散、过滤与去重                    │
 │       （语言偏好、标签黑名单、成人内容过滤、排除已读作品）       │
 └─────────────────────────────┬───────────────────────────────┘
                               ▼
                        最终呈现的推荐信息流
```

### 5 大推荐方向

| 推荐方向 | 标识 | 生成逻辑 |
| :--- | :--- | :--- |
| **口味** | `TASTE` | 提取本地书库标签并依据阅读进度、完成度与最近阅读时间加权，在已启用的源中抓取匹配你核心偏好的作品。 |
| **热门** | `POPULAR` | 抓取各内容源当前最热门、受众最广的头部作品。 |
| **最新** | `NEW` | 捕捉各源最新收录或刚刚更新的作品。 |
| **探索** | `EXPLORE` | 主动发掘你尚未涉足的体裁或题材标签，防止推荐陷入信息茧房。 |
| **社区** | `COMMUNITY` | 结合去中心化 Nostr 评分索引快照，计算协同相似度（“因为你喜欢《…》”）。 |

## 与社区功能的交集

当你在 `设置 → 服务 → 社区` 中开启了[社区功能](./community.md)后，推荐系统将获得更强的数据支撑：

### 1. 社区精选（协同过滤推荐）
- 系统从书库中挑选出你的高分作品（打分 $\ge 7$ 分）、收藏夹作品或已读完作品作为“推荐种子”。
- 匹配静态快照中预先计算好的**作品间余弦相似度矩阵**（Item-Item Cosine Similarity）。
- 若全网其他高分读者在喜欢你的种子作品的同时也高度赞赏作品 X，作品 X 就会被推荐出来，附带明确的推荐理由：**“因为你喜欢《…》”**。
- 系统会在你本地安装的源中自动搜索匹配可读的条目，无需手动搜寻。

### 2. 社区质量调优（`SuggestionQuality`）
即便是源推荐（口味、热门或最新），Kototoro 也会参考社区快照中的评分置信度：
- **置信样本（$W \ge 5.0$）**：当一部作品积累了足够多的社区评分时，它的贝叶斯均分会介入最终排序。
- **高分提权（$\text{Score} > 7.0$）**：广受赞誉的作品会获得高达 $1.6\times$ 的加权，优先排在前面。
- **低分抑制（$\text{Score} < 6.0$）**：若全网读者一致认为该作质量低下（低于 6 分），其综合权重会被削减至 $0.4\times$，有效剔除标题党与垃圾条目。

### 3. 详情页的“相似作品”
在任何作品的详情页面中，“喜欢这部的读者也喜欢”轮播卡片会展示与之关联度最高的作品，并标明共同评分读者数或共享标签数。

## 纯本地隐私安全保障

Kototoro 的推荐算法全链路在设备本地运行：
- **无上报、无埋点**：阅读历史、收藏进度与书库内容绝对不会被上传至任何推荐中枢。
- **离线算法**：逆文档频率（TF-IDF `TagRarity`）、品味向量聚类与 MMR 多样性重排均在本地后台协程中完成。
- **静态快照匹配**：社区协同数据通过通用的静态 JSON 快照下发，与本地书库的求交计算完全在客户端进行。

## 个性化定制与筛选

进入 **设置 → 服务 → 推荐**，可对推荐引擎进行精细微调：

### 1. 内容源偏好
- **优先来源**：挑选你最信任的优质来源，推荐引擎会优先从这些源中检索候选。
- **排除来源**：彻底禁用某些质量不稳定或不感兴趣的来源。

### 2. 标签黑白名单
- **标签黑名单**：彻底隐藏带有特定标签的作品（如“血腥”、“后宫”、“纯爱”等）。
- **优先标签（白名单）**：固定加权你特别喜爱的分类。
- **全局黑名单**：同步遵循在 `设置 → 浏览` 中设定的全应用标签过滤规则。

### 3. 语言与区域
- **按语言筛选**：仅匹配系统语言或你指定阅读语言的内容源。

### 4. 成人内容过滤
- 勾选 **排除成人内容** 后，推荐流将剔除所有 18+ 或 R18 来源及带有成人标签的作品。

### 5. 每日轮转与一键换一批
- 推荐结果基于当天日期的伪随机种子生成，全天保持稳定，避免频繁闪烁。
- 点击推荐页顶部的 **换一批** 按钮可即时刷新计算种子，拉取全新一批推荐候选。
