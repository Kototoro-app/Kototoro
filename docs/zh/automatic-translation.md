# 自动翻译与 OCR

Kototoro 能够在阅读器内直接对漫画页面与小说章节进行实时翻译。翻译是可选的增强功能；若关闭或某页失败，原图与普通阅读完全不受影响。

---

## 工作机制

Kototoro 采用两阶段流水线：
1. **文本检测与识别**：检测画面中的文字气泡边界，并调用 OCR 引擎识别文字内容。
2. **文本翻译与图层渲染**：将提取的文字送交翻译引擎，并将翻译结果以文字图层无缝贴合在原图对应位置上。阅读器顶部常驻“原图/译文”快捷切换开关。

流水线提供两种翻译模式：

| 翻译模式 | 运行方式 |
| :--- | :--- |
| **本地（Local）** | 优先调用本地配置的 ONNX 离线翻译模型，若未配置则回退至设备内置的 ML Kit 翻译。无需调用外部远程付费 API。 |
| **仅 API（API only）** | 将文字送交配置的在线翻译服务商（如 OpenAI、DeepSeek、Google、自定义接口等）。 |

---

## 配置入口

打开 `设置 → AI`。AI 配置中心整合了以下功能分区：

- **本地模型管理**：下载与管理 OCR 检测、识别以及画面超分辨率模型。
- **在线翻译服务**：配置翻译 API 接口地址、密钥（API Key）与模型名称。
- **翻译设置**：切换翻译模式、OCR 精度、源语言与目标语言。
- **图像超分辨率**：RealCUGAN、Real-ESRGAN、Anime4K 画面放大设置。
- **TTS 语音朗读**：小说听书设置。
- **视频画质增强**：Anime4K 视频滤镜预设。

---

## 首次配置流程

### 1. 基础本地翻译（推荐新手）

1. 进入 `设置 → AI → 翻译`。
2. 翻译模式选择 **本地**。
3. 目标语言选择你的母语（如中文）。源语言建议保持 **自动**。
4. **OCR 模式**保持为 **基础**（基于设备内置 ML Kit，无需额外下载几十兆模型）。
5. 打开一部生肉漫画章节，在阅读器菜单中开启 **漫画翻译**。

### 2. 高级离线 OCR 模式

对于气泡文字较小、竖排日语排版或艺术字等复杂页面，可启用 **高级 OCR**：
1. 在 `设置 → AI → 翻译` 中将 OCR 模式切换为 **高级**。
2. 系统会提示下载高级离线 OCR 数据包（包含优化的文本检测与语言识别模型）。
3. 下载完成后，点击设置按钮进入 **本地模型管理**，可按需挑选或替换检测模型（如 PaddleOCR、MangaOCR）。
